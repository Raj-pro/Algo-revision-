Prim’s Minimum Spanning Tree Algorithm

Grow one connected tree by repeatedly adding the cheapest edge leaving it.

1. Grow the MST

Start at a vertex. Each step chooses the lowest-weight edge connecting a visited vertex to an unvisited vertex.

2. Edge choices

Green = included in the MST. Orange dashed = currently considered. Grey = not selected.

Prim’s rule: choose the cheapest edge that crosses from the visited set to the unvisited set.
Stop: when every vertex is visited. The MST has V − 1 edges.

3. Kruskal vs. Prim

  • Kruskal: globally sorts edges and joins separate components, avoiding cycles.
  • Prim: starts from one vertex and grows a single tree.
  • Both produce a minimum spanning tree for a connected, weighted, undirected graph.
With a binary heap: O(E log V)

A simple array-based implementation runs in O(V²). Auxiliary space is O(V), excluding graph storage.
