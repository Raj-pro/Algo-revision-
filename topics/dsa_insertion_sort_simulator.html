Insertion Sort

Build a sorted section by inserting each new element into its correct place.

1. Interactive sorting

Like arranging playing cards in your hand: take the next value, shift larger values right, and insert it.

Yellow: key being insertedRed: element being shiftedGreen: sorted section

2. How it works

  1. Assume the first element is sorted.
  2. Take the next element as the key.
  3. Shift sorted elements that are greater than the key one position right.
  4. Insert the key into the empty position.
  5. Repeat until all elements are inserted.
Example: [3, 7 | 5] → shift 7 → [3, 7, 7] → insert 5 → [3, 5, 7]

3. Complexity

Best case: O(n), when already sorted.

Average / worst case: O(n²).

Auxiliary space: O(1).

Insertion Sort is stable and works well for small or nearly sorted arrays.
