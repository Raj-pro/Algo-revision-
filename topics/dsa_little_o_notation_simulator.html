Little-o Notation (o)

Learn how little-o means a function grows strictly slower than another function in the long run.

1. The main idea

Little-o describes a strict upper growth bound. Saying f(n) = o(g(n)) means f grows slower than g as n becomes very large.

f(n) = o(g(n))
Key difference: Big O allows the same growth order. Little-o requires strictly slower growth.

Example 1

n = o(n²)
Because n / n² = 1/n → 0.

Example 2

n² is NOT o(n²)
Because n² / n² = 1, which does not approach zero.

Choose a comparison

n = o(n²) is true: the ratio approaches zero.

3. How to test little-o

For many standard functions, calculate this limit:

lim n→∞ f(n) / g(n) = 0

If the limit is zero, then f(n) = o(g(n)). If the limit is a positive constant, little-o does not hold (though Big O may hold).

Worked example: n = o(n²)

  1. Divide the functions: n/n² = 1/n.
  2. As n gets larger, 1/n gets closer to zero.
  3. Therefore, n = o(n²).
Remember: n² = O(n²) is true, but n² = o(n²) is false. Big O can match the same order; little-o must be strictly slower.
