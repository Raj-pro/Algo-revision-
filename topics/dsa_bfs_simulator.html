Breadth-First Search (BFS)

Explore a graph level by level using a queue.

1. Run BFS

Start from A. BFS visits nearby vertices first, then moves to the next level.

2. Queue and visit order

Queue (FIFO): first in, first out.
Visited order: —
When a vertex is first discovered, mark it visited and enqueue it. This prevents adding it repeatedly.

3. BFS properties

  • Visits vertices in increasing number of edges from the source.
  • Finds shortest paths in an unweighted graph (or one where all edges have equal weight).
  • With adjacency lists, time complexity is O(V + E).
Space: O(V)

BFS uses a queue; DFS, the next topic, explores deeply before backtracking.
