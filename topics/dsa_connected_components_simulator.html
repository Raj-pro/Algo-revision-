3. Simple explanation

A connected component is a maximal group of vertices where every vertex can reach every other vertex by following edges.

  1. Choose an unvisited vertex.
  2. Run BFS or DFS from it.
  3. All vertices reached belong to one component.
  4. Repeat from another unvisited vertex until none remain.
Time: O(V + E) using adjacency lists
Space: O(V)
