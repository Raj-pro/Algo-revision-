Floyd–Warshall Algorithm

Find shortest distances between every pair of vertices using dynamic programming.

1. Run Floyd–Warshall

The matrix starts with direct edge weights. ∞ means no known path. Each step allows one more intermediate vertex.

Starting distance matrix loaded.

2. Core idea

For every pair i, j: ask whether going from i to j through intermediate vertex k is shorter.
D[i][j] = min(D[i][j], D[i][k] + D[k][j])

Repeat this for every vertex k as an allowed intermediate.

Example: if A→B costs 3 and B→C costs 4, then A→C can improve to 7 if it was previously larger or ∞.

3. Complexity and notes

Time: O(V³)
Space: O(V²)
  • Works for directed or undirected weighted graphs.
  • Can handle negative edge weights.
  • Does not work correctly when a negative-weight cycle exists; a negative diagonal entry after the algorithm signals one.
