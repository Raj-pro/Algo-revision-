Graph Representations

Represent the same graph using an adjacency matrix or an adjacency list.

1. Explore the graph

Choose a sample graph. This example is undirected and unweighted.

An edge connects two vertices.

2. Adjacency matrix

Rows and columns represent vertices. A 1 means an edge exists; 0 means no edge.

For an undirected graph, the matrix is symmetric around the main diagonal.

3. Adjacency list

Each vertex stores a list of its neighbors.

An adjacency list stores only existing edges, so it is often more space-efficient for sparse graphs.

4. Compare storage

Adjacency matrix: uses Θ(V²) space. Checking whether an edge exists takes Θ(1).
Adjacency list: uses Θ(V + E) space. Iterating through neighbors of vertex v takes Θ(degree(v)).

V = number of vertices; E = number of edges.
