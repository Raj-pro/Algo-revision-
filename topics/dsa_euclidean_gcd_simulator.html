Euclidean Algorithm for GCD

Find the greatest common divisor by repeatedly using remainders.

1. Try your own numbers

Enter two non-negative integers. At each step, replace (a, b) with (b, a mod b).

GCD6
Remainder steps3
Time complexityO(log min(a,b))
GCD(48, 18) = 6.

2. Follow the remainder steps

When the second number becomes 0, the first number is the GCD.

3. Example by hand

Find GCD(48, 18):

48 = 18 × 2 + 12
18 = 12 × 1 + 6
12 = 6 × 2 + 0

The last non-zero remainder is 6, so GCD(48,18) = 6.

Why does it work? The common divisors of a and b are exactly the common divisors of b and a mod b. Each step reduces the numbers until the remainder is zero.

4. Code idea

while (b != 0) {
    remainder = a % b;
    a = b;
    b = remainder;
}
return a;

What is %?

The modulo operator gives the remainder. For example, 48 % 18 = 12.

Euclid’s algorithm runs in logarithmic time relative to the smaller input, often written O(log min(a,b)).
