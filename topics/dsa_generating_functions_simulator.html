Generating Functions

Turn a sequence into a power series so patterns and recurrence relations become easier to study.

1. Build a generating function

For a sequence a₀, a₁, a₂, … its ordinary generating function is A(x) = a₀ + a₁x + a₂x² + …

7
A(x) = 1 + x + x² + …
For |x| < 1, 1 + x + x² + … = 1/(1−x).

2. Why it is useful

A generating function stores every term of a sequence inside one algebraic expression.

Sequence: the values a₀, a₁, a₂, …
Encode: multiply aₖ by xᵏ and add all terms.
Manipulate: use algebra to discover a formula or solve a recurrence.
Decode: read the coefficient of xᵏ to recover aₖ.
For the all-ones sequence, A(x) = 1 + x + x² + … = 1/(1−x), when |x| < 1.

3. Common examples

All ones

1, 1, 1, … → 1/(1−x)

Geometric series: every coefficient is 1.

Natural numbers

0, 1, 2, 3, … → x/(1−x)²

The coefficient of xᵏ is k.

Powers of 2

1, 2, 4, 8, … → 1/(1−2x)

The coefficient of xᵏ is 2ᵏ.

Fibonacci numbers

0, 1, 1, 2, 3, … → x/(1−x−x²)

Using F₀ = 0, F₁ = 1 and Fₙ = Fₙ₋₁ + Fₙ₋₂.

These are ordinary generating functions; the algebraic expressions are interpreted as formal power series, and also converge for x values inside their radius of convergence.

4. Small worked example

For the sequence 1, 1, 1, 1, …:

  1. Write \(A(x)=1+x+x^2+x^3+\cdots\).
  2. Multiply by x: \(xA(x)=x+x^2+x^3+\cdots\).
  3. Subtract: \(A(x)-xA(x)=1\).
  4. Factor: \(A(x)(1-x)=1\).
  5. Therefore, \(A(x)=\frac{1}{1-x}\).

5. Quick check
