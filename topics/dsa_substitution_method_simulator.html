Recurrence Solving: Substitution Method

Guess a bound, expand the recurrence, and use induction to prove it.

1. Pick a recurrence

4
Likely boundΘ(n log n)
PatternHalve + 2 calls
BaseT(1)=1
Each expansion creates two subproblems of size n/2 plus n work at the current level.

2. Expansion steps

Watch how the recurrence unfolds. For substitution proofs, the algebraic pattern suggests a bound to prove.

3. Worked example

Consider \(T(n)=2T(n/2)+n\), with \(T(1)=1\) and n a power of 2.

T(n) = 2T(n/2) + n
= 2[2T(n/4) + n/2] + n = 4T(n/4) + 2n
= 8T(n/8) + 3n
After k levels: T(n) = 2ᵏT(n/2ᵏ) + kn
Stop when n/2ᵏ = 1, so k = log₂ n
T(n) = nT(1) + n log₂ n = Θ(n log n)

4. What makes it the substitution method?

  1. Guess a bound, often from expansion or another method.
  2. Assume the bound holds for smaller inputs.
  3. Substitute that assumption into the recurrence.
  4. Simplify and verify the bound, including base cases.
Example proof idea: if \(T(n)=2T(n/2)+n\), guess \(T(n)=O(n\log n)\). Assume \(T(n/2)\le c(n/2)\log(n/2)\), then substitute and choose constants to establish the bound for sufficiently large n.
