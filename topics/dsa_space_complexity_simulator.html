3. Understand the difference

Input space vs auxiliary space

  • Input space: memory already occupied by the given input.
  • Auxiliary space: extra memory the algorithm uses while working.
  • Space complexity: memory growth as input size increases; courses may count total space or focus on auxiliary space, so read the question carefully.

Example: copy an array

copy = []
for item in array:
    copy.append(item)

For n input elements, the copy stores n more elements. Auxiliary space is O(n).

In-place idea: an algorithm that modifies the existing array and uses only a few extra variables may use O(1) auxiliary space.
