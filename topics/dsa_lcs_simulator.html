Longest Common Subsequence (LCS)

Find the longest sequence shared by two strings without changing character order.

1. Try your own strings

A subsequence can skip characters, but the remaining characters must stay in order.

Build the table to begin.

2. Dynamic programming table

dp[i][j] = LCS length for the first i characters of String 1 and first j characters of String 2.

If characters match: dp[i][j] = dp[i−1][j−1] + 1
If they differ: dp[i][j] = max(dp[i−1][j], dp[i][j−1])

3. Result

Build the table to reveal the LCS.
Time: O(mn)
Space: O(mn)

m and n are the lengths of the two strings.
