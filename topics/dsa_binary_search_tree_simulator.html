Binary Search Tree (BST)

Insert values, search for a value, and explore inorder traversal.

1. Interactive BST

Rule: values smaller than a node go left; larger values go right. Start with the sample values or insert your own.

2. Traversal and properties

Inorder traversal visits left subtree, node, then right subtree. In a BST, it lists values in sorted order.

Search: compare the target with the current node; go left if smaller, right if larger.
Average time: O(log n) in a balanced BST. A skewed BST can take O(n).
Inorder: Left → Root → Right

3. Complexity

OperationAverage / balancedWorst case
SearchO(log n)O(n)
InsertO(log n)O(n)
DeleteO(log n)O(n)

The worst case occurs when the tree becomes like a linked list.
