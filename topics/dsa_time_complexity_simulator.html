3. Read the code idea

Visit every item

for (i = 0; i < n; i++) {
    print(array[i]);
}

How to analyze it

  1. Identify the input size, usually n.
  2. Count how many times the main operation executes.
  3. Ignore constants and lower-order terms for Big O.
  4. Describe the growth rate as n becomes large.
Remember: Time complexity describes growth in work, not a guaranteed number of seconds.

4. Quick check

A loop visits each of the n array elements exactly once. What is its time complexity?
