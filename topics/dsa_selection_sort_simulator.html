Selection Sort

Find the smallest remaining element and place it in the next sorted position.

1. Interactive sorting

Selection Sort scans the unsorted part to find the minimum, then swaps it into place.

Yellow: current minimumRed: swapped elementsGreen: sorted prefix

2. Algorithm idea

  1. Start at the first unsorted index.
  2. Scan the rest of the array and find the minimum.
  3. Swap that minimum with the first unsorted element.
  4. Move the sorted boundary one position right and repeat.
Example: [4, 2, 3] → minimum is 2 → swap with 4 → [2, 4, 3]

3. Complexity

Best, average, worst time: O(n²)

Auxiliary space: O(1)

Selection Sort uses relatively few swaps, but standard selection sort is not stable.
