3. Why is it faster?

Ordinary divide-and-conquer matrix multiplication needs 8 submatrix multiplications. Strassen uses 7, replacing the eighth multiplication with extra additions and subtractions.

T(n) = 7T(n/2) + Θ(n²)

By the Master Theorem:

T(n) = Θ(nlog₂ 7) ≈ Θ(n2.807)

Ordinary matrix multiplication takes Θ(n³) time. Strassen's asymptotic time is lower for sufficiently large matrices, though practical performance depends on implementation and matrix size.

4. Pseudocode idea

strassen(A, B): if matrix is small: multiply directly split A into A11, A12, A21, A22 split B into B11, B12, B21, B22 compute M1 ... M7 using 7 recursive calls combine M1 ... M7 into C11, C12, C21, C22 return C

For matrix sizes that are not powers of two, implementations can pad the matrices or use another suitable strategy.
