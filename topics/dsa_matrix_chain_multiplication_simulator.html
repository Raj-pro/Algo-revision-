2. Dynamic programming table

dp[i][j] stores the minimum cost to multiply Aᵢ through Aⱼ.

Recurrence:
dp[i][j] = min over i ≤ k < j of
dp[i][k] + dp[k+1][j] + pᵢ₋₁ × pₖ × pⱼ

3. Why does order matter?

Matrix multiplication is associative: the final result is the same whichever valid order you use. But the number of scalar multiplications can be very different.

Time: O(n³)
Space: O(n²)

n is the number of matrices in the chain.
