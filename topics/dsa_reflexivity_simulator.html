Reflexivity Property

Learn the reflexive rule used in asymptotic notation: every function is asymptotically bounded by itself.

1. What is reflexivity?

Reflexivity means a function can be compared with itself. In asymptotic notation, the standard reflexive rules are:

f(n) = O(f(n))
f(n) = Ω(f(n))
f(n) = Θ(f(n))

For non-negative functions (under the usual asymptotic assumptions), each is true because the function is equal to itself.

Easy analogy: If your height is 170 cm, then your height is equal to your own height. There is no comparison gap.

3. Why it matters in asymptotic notation

  1. Big O: \(f(n)=O(f(n))\) — f is an upper bound for itself.
  2. Omega: \(f(n)=\Omega(f(n))\) — f is a lower bound for itself.
  3. Theta: \(f(n)=\Theta(f(n))\) — f has the same growth rate as itself.

For example, if f(n)=n²+3n, then f(n)=Θ(f(n)). We don't need to simplify anything: the same function appears on both sides.

Don't confuse: Reflexivity is a property/rule. It is not a separate algorithm and does not mean that every two different functions are equivalent.
