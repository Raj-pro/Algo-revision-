Radix Sort

Sort numbers digit by digit, starting with the least significant digit.

1. Interactive radix sort

This simulator uses base-10 LSD Radix Sort. On each pass, it stably groups numbers by the current digit: ones, tens, then hundreds.

Digit buckets

2. How it works

  1. Find the maximum number to know how many digit positions are needed.
  2. Stable-sort all values by the ones digit.
  3. Stable-sort the result by the tens digit.
  4. Continue for hundreds, thousands, and so on until the largest digit is processed.
Example: 21, 13, 12 → sort by ones → 21, 12, 13 → sort by tens → 12, 13, 21.

3. Complexity

Time: O(d(n + b))

Space: O(n + b)

Here n = number of values, d = number of digits, and b = base (10 for decimal digits).

Radix Sort is non-comparison-based and relies on a stable digit-sorting step.
