Little-Omega Notation (ω)

Learn how little-omega expresses a function that grows strictly faster than another function.

1. The main idea

Little-omega describes a strict lower growth bound. Saying f(n) = ω(g(n)) means f grows strictly faster than g as n becomes very large.

f(n) = ω(g(n))
Memory trick: Little-o means strictly slower; little-omega means strictly faster.

Example 1

n² = ω(n)
Because n²/n = n → ∞.

Example 2

n is NOT ω(n)
Because n/n = 1, which does not approach infinity.

Choose a comparison

n² = ω(n) is true: the ratio approaches infinity.

3. How to test little-omega

For many standard functions, calculate this limit:

lim n→∞ f(n) / g(n) = ∞

If the limit is infinity, then f(n) = ω(g(n)). If the limit is a positive constant, little-omega does not hold.

Worked example: n² = ω(n)

  1. Divide the functions: n²/n = n.
  2. As n grows, the ratio grows without bound.
  3. Therefore, n² = ω(n).
Important distinction: n² = Ω(n) is true, but n² = ω(n) is a stronger claim: it says n² grows strictly faster than n, not just at least as fast.
