Heap Sort

Turn an array into a max-heap, then repeatedly move the maximum to the end.

1. Watch heap sort

Enter integers, then advance one operation at a time.

Array state
Enter values and click Start sorting.

2. What each color means

Yellow: current root / element being moved.
Blue: elements still in the heap.
Green: elements already in their final sorted positions.

Heap sort first builds a max-heap. Since the maximum is at the root, it swaps the root with the last element of the heap, shrinks the heap, and restores the heap property.

3. Algorithm

heapSort(A): buildMaxHeap(A) for end = n - 1 down to 1: swap(A[0], A[end]) heapSize = end siftDown(A, 0, heapSize) return A

Using a max-heap produces ascending order. A min-heap can be used with a different arrangement to produce descending order.

4. Complexity and properties

Time: O(n log n)

Heap construction is O(n), followed by O(log n) heap repair for up to n removals.

Auxiliary space: O(1)

In-place heap sort uses constant extra space, excluding the animation's display state.

Stable? No, standard heap sort is not stable.
In-place? Yes, the standard array-based algorithm is in-place.
