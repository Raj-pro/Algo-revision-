2. What is happening?

Merge sort repeatedly divides the array into smaller parts until each part has one element.

Core idea

Divide: split the array into halves.
Conquer: recursively sort each half.
Combine: merge the sorted halves in order.
Time: Θ(n log n)

3. Complexity

Time complexity

Each level does about Θ(n) merging work. There are Θ(log n) levels.

Θ(n) × Θ(log n) = Θ(n log n)

Best, average, and worst cases are all Θ(n log n).

Space complexity

The common array-based implementation uses extra temporary storage for merging.

Θ(n) auxiliary space

This is the standard result for a typical implementation, excluding small recursion-stack details.
