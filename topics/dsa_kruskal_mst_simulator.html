Minimum Spanning Tree: Kruskal’s Algorithm

Connect every vertex at minimum total cost without creating a cycle.

1. Build the MST step by step

Kruskal considers edges from smallest weight to largest. Accept an edge only if it does not create a cycle.

Press Next edge to begin.

2. Sorted edge list

Green edges are accepted into the tree. Red dashed edges are rejected because they would make a cycle.

Rule: choose the cheapest available edge that connects two different components.
Stop when: the MST contains V − 1 edges. Here V = 6, so it needs 5 edges.

3. Why no cycles?

A spanning tree connects all vertices using exactly V − 1 edges. If an added edge connects vertices already connected by the chosen edges, it creates a cycle, so Kruskal rejects it.

In an implementation, a Disjoint Set Union (Union-Find) structure efficiently checks whether two vertices are already in the same component.

Time: O(E log E)

Auxiliary space: typically O(V) for Union-Find, excluding graph storage and sorting storage.
