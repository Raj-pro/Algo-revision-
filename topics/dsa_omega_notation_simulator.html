Omega Notation (Ω)

Learn how Ω describes a lower bound on an algorithm's growth, using a simple visual example and an interactive graph.

1. What does Ω mean?

Omega notation gives an asymptotic lower bound. It describes a rate of growth that a function is at least as large as, for sufficiently large input sizes.

f(n) = Ω(g(n))

Informally: after some point, f(n) grows at least as fast as a constant multiple of g(n).

Formal definition

f(n) = Ω(g(n)) if there are constants c > 0 and n₀ such that
f(n) ≥ c · g(n) for every n ≥ n₀.
Easy memory trick: Big O = upper bound; Omega = lower bound; Theta = tight bound (both).

Choose an example

For f(n) = 3n + 2, a valid lower bound is Ω(n).

3. Step-by-step example

Let f(n) = 3n + 2. We want to show that f(n) = Ω(n).

  1. Choose g(n) = n.
  2. Choose a positive constant, for example c = 1.
  3. Check: 3n + 2 ≥ 1 × n for all n ≥ 1.
  4. So 3n + 2 = Ω(n).

A function can have more than one valid lower bound. Ω(n) is a useful bound here; Ω(1) is also technically true, but less informative.

Algorithm intuition

Suppose an algorithm must inspect every item in an array. It performs at least n inspections, so its running time has a lower bound of Ω(n), under this model.

Important distinction: Ω is a mathematical lower bound, not automatically the same as “best case.” Best-case complexity describes performance on the easiest inputs; Ω can describe a bound on a function or a specific case, depending on what function is being analyzed.
