Linear Search

Check each element one by one until the target is found or the array ends.

1. Try the animation

2. How it works

Step 1: Start at index 0, the first element.
Step 2: Compare the current value with the target.
Step 3: If they match, stop. Otherwise move to the next index.
Step 4: If you reach the end, the target is not present.

Example

Array: [14, 7, 23, 5, 18, 9], target = 18.

Check 14 → 7 → 23 → 5 → 18. Found at index 4 after 5 comparisons.

Worst-case time: O(n)

3. Complexity

Best case

O(1)

The first element is the target.

Average / worst case

O(n)

You may need to inspect many or all elements.

Space complexity for the iterative algorithm is O(1).
