Transitive Closure of a Directed Graph

Find out whether each vertex can reach every other vertex, using Warshall’s algorithm.

1. Build reachability

1 means a path exists; 0 means no path is currently known. Click Next k to allow another intermediate vertex.

2. What is transitive closure?

It answers a yes/no question: Can vertex i reach vertex j by following one or more directed edges?

Example: if A → B and B → C, then A can reach C, even if there is no direct edge A → C.
R[i][j] = R[i][j] OR (R[i][k] AND R[k][j])

Unlike Floyd–Warshall, this computes reachability, not shortest distances.

3. Complexity

Time: O(V³)
Space: O(V²)

The algorithm considers each possible intermediate vertex k for every pair (i, j).

4. Quick check

If A → B and B → C, should the closure mark A can reach C?
