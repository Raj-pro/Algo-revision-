Commutativity

Learn when swapping the order of two operands leaves a result unchanged—and why this is different from asymptotic notation rules.

1. What is commutativity?

Commutativity means changing the order of operands does not change the result. For example:

a + b = b + a
a × b = b × a
3 + 5

= 8

5 + 3

= 8

Important for your notes: Commutativity is a standard property of operations such as addition and multiplication. It is not usually listed as a separate standard asymptotic-notation rule in the same way as reflexivity and transitivity, so your class may be using the term in a specific context.

3. Which operations are commutative?

Usually commutative

  • Addition: a+b=b+a
  • Multiplication: ab=ba
  • Set union: A∪B=B∪A
  • Logical AND/OR: order does not change the truth value

Not commutative in general

  • Subtraction: 8−3 ≠ 3−8
  • Division: 8÷2 ≠ 2÷8
  • Matrix multiplication: AB may not equal BA
DSA connection: If you reorder terms in an expression or combine values in an algorithm, make sure the operation allows it. Subtraction and division generally do not.
