2. What is an articulation point?

A vertex is an articulation point if removing it (and its incident edges) splits one connected component into more components.

In this graph, removing C separates the left triangle from the right triangle.

3. Biconnected components

A biconnected component is a maximal subgraph that has no articulation vertex within that subgraph. In an undirected graph, this is often described through vertex-biconnectivity.

4. How DFS finds articulation points

  • Track disc[u]: when vertex u is first discovered.
  • Track low[u]: the earliest discovery time reachable from u's DFS subtree using tree edges and at most one back edge.
  • For a non-root vertex u, if a child v has low[v] ≥ disc[u], u is an articulation point.
  • The DFS root is an articulation point if it has more than one DFS-tree child.

Complexity: O(V + E) time and O(V) auxiliary space with adjacency lists.
