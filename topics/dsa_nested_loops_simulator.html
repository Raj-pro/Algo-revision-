3. Compare the code

Independent nested loops

for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) {
        work();
    }
}

Outer loop: n iterations. Inner loop: n iterations per outer iteration. Total: n × n = n².

Dependent nested loops

for (i = 0; i < n; i++) {
    for (j = 0; j <= i; j++) {
        work();
    }
}

The inner loop runs 1, then 2, then 3, and so on. Total = 1 + 2 + … + n = n(n + 1)/2, which is still O(n²).

Important: “Dependent” does not automatically mean a different Big O class. Count the total iterations, then simplify.
