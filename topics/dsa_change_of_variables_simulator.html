Change of Variables Method

Transform a difficult recurrence into a simpler one by substituting a new variable.

1. Try a recurrence

Choose an example, then follow the substitution. This method is useful when the recurrence has awkward input sizes or a non-standard shape.

T(n) = T(√n) + 1
256
Let m = log₂ n. Then √n becomes 2^(m/2), so the new variable makes the shrinking pattern easier to inspect.

2. Substitution steps

3. Worked example: T(n) = T(√n) + 1

Step 1: The input shrinks from n to √n, which can be awkward to handle directly.
Step 2: Set \(m=\log_2 n\), so \(n=2^m\).
Step 3: \(\sqrt n=2^{m/2}\). Define \(S(m)=T(2^m)\).
Step 4: The recurrence becomes \(S(m)=S(m/2)+1\).
Step 5: Each step halves m, so there are \(\Theta(\log m)\) levels.
T(n) = Θ(log log n)

Assuming a constant-size base case. Changing the logarithm base only changes constant factors.

4. Another common transformation

For a recurrence like \(T(2^m)=2T(2^{m-1})+2^m\), define \(S(m)=T(2^m)\). Then rewrite every occurrence of n using \(n=2^m\), giving \(S(m)=2S(m-1)+2^m\). Solve the recurrence in m, then replace \(m\) with \(\log_2 n\).

Recipe: choose a new variable → rewrite every term → solve the simpler recurrence → substitute back.

5. Quick check

For \(T(n)=T(\sqrt n)+1\), after setting \(m=\log_2 n\), which recurrence do we get for \(S(m)=T(2^m)\)?
