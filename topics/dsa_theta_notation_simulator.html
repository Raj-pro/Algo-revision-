Theta Notation (Θ)

Understand a tight asymptotic bound: when a function is bounded both above and below by the same growth rate.

1. What does Θ mean?

Theta notation describes a tight asymptotic bound. It means a function grows at the same order as another function, up to constant factors, for sufficiently large inputs.

f(n) = Θ(g(n))

Formal definition

f(n) = Θ(g(n)) when positive constants c₁, c₂ and n₀ exist such that
c₁g(n) ≤ f(n) ≤ c₂g(n)
for all n ≥ n₀.
Memory trick: O gives an upper bound, Ω gives a lower bound, and Θ gives both at once.

3. Worked example

Let f(n) = 3n + 2. Show that it is Θ(n).

  1. Choose g(n) = n.
  2. For n ≥ 1, we have n ≤ 3n + 2.
  3. Also, 3n + 2 ≤ 5n for n ≥ 1.
  4. Therefore, 1·n ≤ 3n + 2 ≤ 5·n.
  5. So 3n + 2 = Θ(n).
Example from exams: 4n² + 3n + 8 = Θ(n²), because the highest-degree term dominates as n becomes large.

Algorithm intuition

If an algorithm scans every item exactly once, its work is both at most proportional to n and at least proportional to n. In that model, its running time is Θ(n).
