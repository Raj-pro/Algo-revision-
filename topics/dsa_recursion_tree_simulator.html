Recursion Tree Method

Break a recurrence into levels, count the work at each level, then add it all up.

Each level has the same total work n; there are log₂ n levels.

2. Tree and level costs

For readability, the drawing shows representative nodes; the level-cost calculation accounts for the full level.

3. Example: T(n) = 2T(n/2) + n

At each node, split into two subproblems and do n work at the current level.

Root: n→Level 1: n/2 + n/2 = n→Level 2: four × n/4 = n

There are approximately \(\log_2 n\) levels, each costing n. Leaves together contribute Θ(n).

Total = Θ(n log n)

4. Method checklist

  1. Draw the root for the original problem.
  2. Expand each recursive call into child nodes.
  3. Calculate the total work at each level.
  4. Find the tree height and leaf cost.
  5. Add level costs to get the total complexity.
The important part is the sum of work across a whole level, not just the work of one node.
