Graph Edge Classification

Understand tree edges, back edges, forward edges, and cross edges in DFS.

1. Choose a graph type

Edge classifications are most informative for directed graphs. Switch examples and step through DFS to see discovery edges and edges to already discovered vertices.

2. Edge types

Tree edge: discovers a new vertex.

Back edge: points from a vertex to an ancestor in the DFS tree.

Forward edge: points from a vertex to a descendant but is not a tree edge.

Cross edge: connects vertices that are neither ancestor nor descendant in the DFS tree.

These four types apply to directed graphs in DFS. In an undirected graph, each edge is generally classified as a tree edge or back edge.

4. Complexity

DFS edge classification takes O(V + E) time with adjacency lists. The DFS traversal and classification require up to O(V) auxiliary space, excluding graph storage.
