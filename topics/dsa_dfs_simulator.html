Depth-First Search (DFS)

Follow one path as deeply as possible, then backtrack.

1. Run DFS

Choose a starting vertex. This simulator explores neighbors in alphabetical order.

2. Stack and visit order

Stack: DFS can use a stack or the program's recursion stack.
Visited order: —
If the current vertex has no unvisited neighbor, DFS backtracks to the previous vertex.

3. How it works

  1. Visit the starting vertex and mark it visited.
  2. Choose an unvisited neighbor and continue deeper.
  3. When no unvisited neighbor remains, backtrack.
  4. Stop when every reachable vertex has been visited.

With an adjacency list, DFS takes O(V + E) time and up to O(V) auxiliary space.
