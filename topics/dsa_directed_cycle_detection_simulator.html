Cycle Detection in Directed Graphs

Detect a directed cycle using DFS and the recursion stack.

1. Interactive graph

Select a graph example, then step through DFS. A cycle is detected when DFS finds an edge to a vertex that is currently active in the recursion path (a gray vertex).

3. Easy explanation

DFS uses three states:

  • White: not visited yet.
  • Gray: currently on the recursion path.
  • Black: finished exploring.

If an edge points to a gray vertex, that vertex is an ancestor still on the active path, so a directed cycle exists.

4. Complexity

Using adjacency lists, cycle detection takes O(V + E) time and O(V) auxiliary space for state and recursion.
