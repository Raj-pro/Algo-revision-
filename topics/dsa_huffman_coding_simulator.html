Huffman Coding

Compress data by giving frequent symbols shorter binary codes.

1. Build the Huffman tree

Each leaf is a character and its frequency. Repeatedly merge the two smallest frequencies.

2. Codes and compression

Read from root to leaf: left = 0 and right = 1. Each character gets a prefix-free code.

Prefix-free: no character’s code is the beginning of another character’s code, so decoding is unambiguous.

3. Fixed-length vs. Huffman coding

For 5 distinct characters, a simple fixed-length binary code needs 3 bits per character because 2 bits can represent only 4 symbols. Huffman coding gives shorter codes to more frequent characters and longer codes to less frequent ones.

Build time: O(k log k)

Here k is the number of distinct symbols; a priority queue is commonly used.
