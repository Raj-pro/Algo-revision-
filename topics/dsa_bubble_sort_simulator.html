Bubble Sort

Sort numbers by repeatedly comparing adjacent elements and swapping them if needed.

2. How Bubble Sort works

  1. Compare two adjacent elements.
  2. If left is greater than right, swap them.
  3. Continue to the end of the unsorted part.
  4. Repeat passes until no swaps are needed.
Example: [4, 2] → compare 4 and 2 → swap → [2, 4]

3. Complexity

Worst / average time: O(n²)

Best time (optimized): O(n), if already sorted and the algorithm stops after a no-swap pass.

Auxiliary space: O(1)

Bubble Sort is stable when equal values are not swapped, but it is inefficient for large arrays.
