Binary Search (Iterative)

Find a target in a sorted array by repeatedly cutting the search range in half.

2. How it works

1. Calculate midpoint: mid = floor((low + high) / 2).
2. Compare: if A[mid] equals the target, stop.
3. Narrow range: if target is smaller, set high = mid − 1; otherwise set low = mid + 1.
4. Repeat: stop when found or low becomes greater than high.
Time: O(log n)

3. Complexity

Time complexity

O(log n)

Each comparison removes about half of the remaining elements.

Space complexity

O(1)

For the iterative version, only a few index variables are needed.

Important: the array must be sorted. Sorting an unsorted array first has its own cost.
