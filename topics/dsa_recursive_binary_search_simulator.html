Recursive Binary Search

The same divide-in-half strategy, implemented using a function that calls itself.

2. Recursive call stack

Every time the function calls itself, a new call is added. Calls return when the target is found or the range is empty.

Base case 1: if low > high, return “not found”.
Base case 2: if A[mid] equals target, return mid.
Recursive case: call the function on only the left or right half.

3. Pseudocode

binarySearch(A, low, high, target): if low > high: return NOT_FOUND mid = floor((low + high) / 2) if A[mid] == target: return mid else if target < A[mid]: return binarySearch(A, low, mid - 1, target) else: return binarySearch(A, mid + 1, high, target)

A recursive function must have a base case; otherwise it may keep calling itself until the call stack overflows.

4. Complexity

Time

O(log n)

The search range halves with each recursive call.

Auxiliary space

O(log n)

The call stack stores one frame per level of recursion.
