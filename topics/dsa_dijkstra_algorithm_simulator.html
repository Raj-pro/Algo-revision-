Dijkstra's Shortest-Path Algorithm

Find shortest distances from one source in a graph with non-negative edge weights.

1. Run Dijkstra

Select a source and advance the algorithm one step at a time. Edge weights are shown on the graph.

Select a source and start.

2. Distance table

∞ means the distance is not known yet. A smaller distance replaces a larger one.

Relaxation: if dist[u] + weight(u,v) is smaller than dist[v], update dist[v].
Greedy choice: repeatedly finalize the unvisited vertex with the smallest tentative distance.

3. How it works

  1. Set source distance to 0 and all other distances to ∞.
  2. Choose the unvisited vertex with the smallest known distance.
  3. Try to improve distances to its neighbors (relax its edges).
  4. Mark that vertex visited and repeat.
Time: O((V + E) log V)

This bound applies to a common implementation using an adjacency list and a binary min-heap. A simple matrix implementation is often O(V²).

4. Important limitation

Dijkstra's algorithm assumes all edge weights are non-negative. It is not correct in general when negative-weight edges exist. Bellman–Ford can handle negative edges and detect reachable negative cycles.
