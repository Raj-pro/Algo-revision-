Priority Queues & Dictionaries

A priority queue serves by priority; a dictionary looks up values by key.

3. Core difference

Priority queue

Retrieves an element based on priority, not merely on when it was inserted.

Common operations: insert, peek highest priority, remove highest priority.

Dictionary / map

Retrieves a value using its key, such as finding a student's mark by roll number.

Common operations: put, get/search, remove.

4. Implementation and complexity

Priority queue using a binary heap: peek O(1); insert O(log n); remove top O(log n).
Dictionary using a hash table: average lookup, insert, and delete O(1); worst case can be O(n).
Dictionary using a balanced search tree: lookup, insert, and delete O(log n).

These complexities depend on the chosen implementation.
