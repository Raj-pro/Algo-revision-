Master Theorem

Quickly solve many divide-and-conquer recurrences using three cases.

1. Enter a recurrence

They grow at the same polynomial rate, so add a logarithmic factor.

3. The three cases

Case 1: f(n) is smaller

If \(f(n)=O(n^{\log_b a-\epsilon})\) for some \(\epsilon>0\):

T(n) = Θ(n^(logᵦ a))

Case 2: same growth

If \(f(n)=Θ(n^{\log_b a}\log^k n)\), k ≥ 0:

T(n) = Θ(n^(logᵦ a) log^(k+1) n)

Case 3: f(n) is larger

If \(f(n)=Ω(n^{\log_b a+\epsilon})\) and the regularity condition holds:

T(n) = Θ(f(n))

Memory hook

Calculate logᵦ a, compare its exponent with p, then choose the matching case. Case 3 also needs a regularity condition.

This interactive classifier uses f(n) = nᵖ. The classic three-case version shown is for polynomially separated or matching terms; more advanced variants cover additional logarithmic factors.

4. Worked example

Merge sort: \(T(n)=2T(n/2)+n\).

  1. a = 2 and b = 2.
  2. \(n^{\log_b a}=n^{\log_2 2}=n\).
  3. Here f(n) = n, so the terms match.
  4. Case 2 gives \(T(n)=\Theta(n\log n)\).
