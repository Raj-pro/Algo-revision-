Min-Heap & Max-Heap

A heap is a complete binary tree that keeps its highest- or lowest-priority value at the root.

1. Build and edit a heap

Choose the heap type, then insert or remove values. The array and tree update together.

Array representation
Ready. Insert a value.

2. Heap property

Min-heap: each parent is less than or equal to its children. The minimum value is at the root.
Max-heap: each parent is greater than or equal to its children. The maximum value is at the root.

A heap is not fully sorted. It only guarantees the parent–child ordering.

Array index (0-based):
Parent of i: floor((i − 1) / 2)
Left child: 2i + 1
Right child: 2i + 2

3. Operations and complexity

Peek root: O(1)

Read the root without removing it.

Insert: O(log n)

Place at the end, then sift up.

Remove root: O(log n)

Move the last value to root, then sift down.

Build heap: O(n)

Bottom-up heap construction is linear time.
