Counting Sort

Sort small-range integers by counting how often each value appears.

1. Interactive counting process

Counting Sort does not compare every pair. It counts each value, then uses those counts to build the sorted output.

Input array

Frequency counts

Sorted output

2. Algorithm

  1. Find the maximum value to determine the count-array size.
  2. Count how many times each value occurs.
  3. Write each value into the output according to its frequency.
Example: [4, 2, 2, 1] → counts: 1 occurs once, 2 twice, 4 once → [1, 2, 2, 4]

This teaching version uses frequency counts. A stable version can use prefix sums and place items into output from right to left.

3. Complexity

Time: O(n + k)

Space: O(k) for counts, plus O(n) for the output in this version.

Here, n is the number of items and k is the range of values (maximum value + 1 for non-negative integers).

Counting Sort is useful when the value range is not much larger than the number of items.
