Transpose Symmetry

In asymptotic notation, this commonly refers to symmetry: swapping the two functions in a Theta relationship keeps the relationship true.

1. What does symmetry mean?

In your asymptotic-rules notes, transpose symmetry most likely refers to the symmetry property of Theta notation:

f(n) = Θ(g(n))
if and only if
g(n) = Θ(f(n))

In simple words, if two functions grow at the same asymptotic rate, swapping their positions does not change the relationship.

Easy analogy: If A is equal in height to B, then B is equal in height to A.

Try an example

The first pair has the same growth rate, so f = Θ(g) and g = Θ(f).

2. Swap the functions

Press the button to switch which function appears first. For Theta-equivalent functions, the conclusion remains true in either direction.

Both functions have the same order of growth.

3. Worked example

Let f(n)=3n+2 and g(n)=n.

  1. For n ≥ 1, n ≤ 3n+2.
  2. Also, 3n+2 ≤ 5n.
  3. Therefore, n ≤ 3n+2 ≤ 5n, so f(n)=Θ(g(n)).
  4. By symmetry, g(n)=Θ(f(n)) too.
Important clarification: Big O by itself is not symmetric. If f=O(g), it does not necessarily follow that g=O(f). The symmetry rule applies to Θ.
