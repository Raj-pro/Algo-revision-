2. Key vocabulary

Node: a value or item in the tree.
Root: the topmost node; it has no parent.
Edge: a link between a parent and child.
Leaf: a node with no children.
Parent / child: directly connected nodes above and below.
Height: the number of edges on the longest path from a node to a leaf. A single-node tree has height 0 by this definition.

3. Binary tree types

General binary tree

Each node has at most two children. A node may have zero, one, or two children.

Strict / full

Every node has either zero children or exactly two children. No node has just one child.

Complete

Every level is full except possibly the last, and the last level is filled from left to right.

Perfect

Every internal node has two children and all leaves are at the same depth.

4. Useful formulas

For a binary tree of height h (height measured in edges):

Maximum nodes = 2h+1 − 1

For a perfect binary tree with L levels, where the root is level 1:

Total nodes = 2L − 1

A binary tree is not automatically a Binary Search Tree (BST). A BST also follows an ordering rule for values.
