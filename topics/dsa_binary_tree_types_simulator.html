Strict, Complete & Full Binary Trees

Compare the shapes and test whether each tree follows the definition.

1. Choose a tree

Select a shape to inspect it and read the checks.

2. How to recognize each type

Strict (full): each node has 0 or 2 children. One-child nodes are not allowed.
Complete: all levels before the last are full; last-level nodes occupy leftmost positions first.
Perfect: every internal node has 2 children and all leaves have equal depth.

Terminology can vary between textbooks. Here, “strict/full” means the 0-or-2-children definition.

3. Quick comparison

Strict does not always mean complete. A strict tree can have leaves at different depths.
Complete does not always mean strict. The last node on the second-last level can have only a left child.
Every perfect binary tree is both strict and complete.
