Sparse and Dense Graphs

Understand how the number of edges affects graph storage and algorithm choices.

1. Adjust the number of edges

This is a simple undirected graph with 6 vertices. Add or remove edges to change its density.

2. Density meter

For a simple undirected graph with no self-loops, the maximum possible number of edges is:

Emax = V(V − 1) / 2

Density = actual edges / maximum possible edges.

“Sparse” and “dense” are relative terms; there is no universal cutoff for every application.

3. Storage trade-off

Matrix: O(V²)

Space depends on the number of possible vertex pairs, even if few edges exist.

Useful when the graph is dense or edge-existence checks are frequent.

List: O(V + E)

Space grows with vertices and actual edges.

Usually a better choice for sparse graphs.
