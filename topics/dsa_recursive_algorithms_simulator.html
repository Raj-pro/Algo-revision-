3. Code and analysis

Countdown

function countdown(n) {
    if (n === 0) return;
    countdown(n - 1);
}

How to analyze recursion

  1. Find the base case: when does the function stop calling itself?
  2. Count how many recursive calls are made.
  3. Work out how many levels/calls are reached.
  4. Estimate maximum simultaneous calls to analyze stack space.
Key idea: total calls determine work; maximum active frames determine call-stack space (assuming constant-size frames).
