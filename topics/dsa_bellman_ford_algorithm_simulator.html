Bellman–Ford Algorithm

Shortest paths even when edges have negative weights — and a way to detect reachable negative cycles.

1. Run the algorithm

This directed graph includes a negative edge. Click Next pass to relax every edge once.

Choose a source to begin.

2. Distance table

Each pass considers all directed edges. Distances may improve over several passes.

Relaxation rule: if dist[u] + weight(u,v) is less than dist[v], update dist[v].
Why V − 1 passes? A shortest simple path can contain at most V − 1 edges when there is no reachable negative cycle.

3. What makes Bellman–Ford special?

  • It supports negative edge weights.
  • It repeats edge relaxation for up to V − 1 passes.
  • One additional pass checks whether any distance can still decrease. If yes, a reachable negative-weight cycle exists.
Time: O(VE)

Space: O(V) for distances and predecessor information, excluding graph storage.
