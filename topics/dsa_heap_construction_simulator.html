Heap Insertion, Deletion & Construction

Compare top-down insertion with bottom-up heap building.

1. Try the algorithms

Choose a max-heap or min-heap, then select a construction method.

Enter values and click Build heap.

2. What's happening?

The simulator shows the current array and heap tree as the algorithm progresses.
Top-down: append each value and sift it upward until parent order is valid.
Bottom-up: start at the last non-leaf node and sift down toward the root. Leaves already satisfy the heap property.
Delete root: move the final array element to the root, remove the old root, then sift down.

3. Complexity to memorize

Top-down build: O(n log n)

Each of n insertions can take O(log n).

Bottom-up build: O(n)

Most nodes are near the leaves and require little or no sifting.

A single insertion or root deletion is O(log n); reading the root is O(1).
