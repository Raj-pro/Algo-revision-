Finding the k-th Smallest Element

Learn how sorting, Quickselect, and Median of Medians can find a rank in an array.

2. Explanation

What does k mean?

For the sorted array [1, 2, 3, 4, 7, 8, 9], k = 1 gives 1; k = 4 gives 4; k = 7 gives 9.
Sorting: simple and useful when you need the entire sorted array.
Quickselect: partitions around a pivot and continues only on the side containing the target.
Median of Medians: uses a carefully chosen pivot for a worst-case linear guarantee.

3. Complexity comparison

Sort then index

O(n log n)

Sort all values and take position k−1.

Quickselect

Average O(n)

Worst case O(n²) with poor pivot choices.

Median of Medians

Worst-case O(n)

More involved pivot selection guarantees progress.

Indexing rule

array[k − 1]

In programming, arrays are commonly zero-indexed.
