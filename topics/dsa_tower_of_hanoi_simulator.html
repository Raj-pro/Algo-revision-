2. Watch the disks move

A disk can only be moved if it is the top disk on its rod, and the destination top disk must be larger.

3. Why does it take so many moves?

To move n disks from A to C:

  1. Move the top \(n-1\) disks from A to B.
  2. Move the largest disk from A to C.
  3. Move the \(n-1\) disks from B to C.
T(n) = 2T(n − 1) + 1

The minimum number of moves is:

T(n) = 2ⁿ − 1

So time complexity is Θ(2ⁿ). The classic recursive implementation uses O(n) stack space because its maximum call depth is n.

Recursive pseudocode

Hanoi(n, source, target, spare):
    if n == 1:
        move source → target
        return
    Hanoi(n-1, source, spare, target)
    move source → target
    Hanoi(n-1, spare, target, source)
