Strongly Connected Components (SCCs)

Find groups of vertices that can all reach one another in a directed graph.

1. Explore the directed graph

Use the component buttons to highlight each strongly connected group. An SCC is a maximal set where every vertex can reach every other vertex following arrow directions.

Choose an SCC to highlight it.

2. Components

SCC 1: {A, B, C}
SCC 2: {D, E}
SCC 3: {F}

A, B, and C form a cycle; D and E form another cycle. F has no return path into either group, so it forms its own SCC.

3. How to find SCCs

Kosaraju's algorithm:

  1. Run DFS and record vertices by finishing time.
  2. Reverse every directed edge to form the transpose graph.
  3. Run DFS on the transpose graph in decreasing finishing-time order.
  4. Each DFS tree found in step 3 is one SCC.

4. Complexity

Kosaraju's algorithm takes O(V + E) time and O(V + E) total auxiliary storage when graph and transpose representations are included.
