2. Formula guide

AP nth term: aₙ = a + (n − 1)d

Start at a, then add the same difference d for each new term.

AP sum: Sₙ = n/2 [2a + (n − 1)d]

The sum is the number of terms divided by 2, multiplied by first + last term.

Remember: AP adds a fixed amount; GP multiplies by a fixed ratio.

3. Connection to algorithm analysis

AP example: 1 + 2 + … + n

This sum appears in dependent loops where the inner loop runs 1, 2, 3, …, n times.

1 + 2 + … + n = n(n + 1)/2 = Θ(n²)

GP example: 1 + 2 + 4 + 8 + …

This doubling pattern can appear in recursive or branching algorithms.

1 + 2 + 4 + … + 2ⁿ = 2ⁿ⁺¹ − 1 = Θ(2ⁿ)

There are n + 1 terms in the displayed sum, starting at 2⁰.
